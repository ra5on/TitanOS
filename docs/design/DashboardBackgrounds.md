# Dashboard-Hintergründe

Die zehn Hintergrundmotive sind eigene, für TitanOS mit dem eingebauten ImageGen-Werkzeug erzeugte Bilder (24. Oktober 2026). Es sind keine Stockfotos und keine Dokumentation tatsächlich fotografierter Orte. Im Produkt liegen sie lokal unter `web/static/backgrounds/` als WebP; zum Anzeigen oder Auswählen wird kein externer Bilddienst aufgerufen. Originalauflösung jeweils etwa 1672 × 941 Pixel, zusammen knapp 1 MB in der ausgelieferten Kodierung.

Die Motive wurden einzeln erzeugt, ohne Referenzbilder. Gemeinsamer Prompt-Rahmen:

> Create one widescreen 16:9 desktop wallpaper for TitanOS NAS dashboard, at least 1536 pixels wide. [Motivbeschreibung] Composition must be calm and readable behind translucent dashboard cards: broad low contrast areas, no text, logos, watermark, UI, frames, people, buildings or collage. This is a single landscape wallpaper asset, not a UI mockup.
