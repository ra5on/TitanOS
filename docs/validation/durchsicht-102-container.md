# Durchsicht 1.01 (PLAN 102) – Container, VMs und Geräte

Auftrag des Inhabers vom 16.11.2026: „die ganze Codebasis prüfen und den Code dementsprechend aufräumen und verbessern, Stabilität reinbringen“. Diese Liste deckt einen der fünf Bereiche ab: `docker`, `vm`, `lxc`, `nvr`, `speech`, `plugins`, `hardware`, `ups`, `homeassistant`, `office`, `toolcatalog` und die zugehörigen Handler in `api/`. Zweig `review/r2`, Stand 1.01.

Vorgehen: Fünf Prüfer haben den Bereich nur lesend durchgesehen. Jeden gemeldeten Fund habe ich im Code nachverfolgt. Behoben wurde nur, wofür ein Test mit dem alten Code fehlschlägt (Ausnahmen sind genannt). Was größer ist, riskanter ist oder eine Entscheidung braucht, steht unter „Notiert“. Funde aus `durchsicht-076.md` sind nicht wiederholt.

Schwere: **hoch** (Datenverlust oder Absturz von titand möglich), **mittel** (Funktion falsch oder bleibt hängen, ohne Ausweg ohne Neustart), **niedrig** (falsche Anzeige, enges Zeitfenster, Aufräumen).
