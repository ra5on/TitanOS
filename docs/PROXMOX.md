# TitanOS in einer virtuellen Maschine

Die aktuelle Anleitung ist unter [VM-Einrichtung](VM.md) zu finden.

Vergrößere die importierte Boot-Festplatte **vor dem ersten Start auf mindestens
32 GiB, empfohlen 64 GiB**. Verwende UEFI und deaktiviere Secure Boot.

Weitere Informationen: [TitanOS](../README.md) · [Downloads](https://github.com/ra5on/TitanOS/releases).
