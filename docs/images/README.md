# TitanOS-Aufnahmen

Die drei JPEG-Aufnahmen zeigen das öffentlich veröffentlichte TitanOS-Image
`2.0.0-titan.1` in einer frisch eingerichteten, separaten Test-VM.
Es wurden keine UI-Mocks oder nachträglichen Bildänderungen verwendet.

- **Desktop:** Startseite nach dem Schließen der Einrichtungstipps.
- **Dateien:** Dateimanager mit eigens angelegten, leeren Beispielordnern.
- **Einstellungen:** Übersicht derselben Testinstallation.

„Titan“ ist ein frei gewähltes Beispielkonto. `10.0.2.15` ist die
[Standardadresse des QEMU-Gastes](https://www.qemu.org/docs/master/system/devices/net.html)
im isolierten NAT-Netz. Die angezeigten Ressourcen gehören zur Test-VM.
Keine Aufnahme enthält Daten eines bestehenden NAS, ein Passwort, einen
Sitzungsschlüssel oder persönliche Dateien. Die JPEGs enthalten keine EXIF-Daten.

Die Test-VM und ihre temporären Zugangsdaten wurden nach den Aufnahmen gelöscht.
Das SVG-Banner verwendet das Titan-Logo aus diesem Repository.
