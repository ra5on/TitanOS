# TitanOS 0.59.1 — Konsolen im Desktop-Modus

Ein **App-Update**: nur titand mit der Weboberfläche, ohne Neustart des NAS, mit automatischem Rückfall.

## Behoben

- **Konsolen in Fenstern:** Im Desktop-Modus öffneten die Knöpfe „Konsole“ (Docker-Container), „Serielle Konsole“ (VMs) und „Shell“/„Konsole“ (Systemcontainer) nichts, und das Programm „Terminal“ blieb leer. Jetzt öffnet jede Konsole im Terminal-Fenster (ist es schon offen, als neuer Reiter), das Terminal-Programm zeigt seine Sitzungen, und am Handy gibt es das Terminal-Panel wieder.
- Die Seite einer Docker-App stürzte ab, wenn die App keine Compose-Datei mitliefert.

## Prüfung

- `npm run check`, `npm test`, Prettier.
- `scripts/test-ui-desktop.mjs` mit neuem Schritt: „Konsole“ auf der Seite einer Docker-App öffnet das Terminal-Fenster mit dem Panel (isolierte Testdaten).
- **Nicht geprüft:** echte Konsolen auf einem NAS in diesem Ablauf.
