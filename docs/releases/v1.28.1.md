# TitanOS 1.28.1 – Änderungen an Agentengesprächen behalten

Wenn der Agent nach der ersten Antwort einen Titel vorschlägt, bleiben der selbst gewählte Gesprächsname, die angeheftete Markierung und das gewählte Projekt erhalten. Das gilt auch, wenn die Änderungen gleichzeitig mit dem Titelvorschlag eintreffen.
