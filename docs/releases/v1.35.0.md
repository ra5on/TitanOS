# TitanOS 1.35 – Persönlicher Agent

- Der Agent öffnet den persönlichen Chat. Auf dem Handy liegen Chat, Aufträge und Einstellungen unter dem Eingabefeld. Am Desktop ergänzt eine Vorschau das Gespräch, sobald ein Ergebnis oder eine Entscheidung ansteht. Farben, Bewegung und Punktgröße lassen sich je Konto einstellen.
- Die Auftragszentrale speichert Fortschritt, Pausen, Freigaben und Ergebnisbelege. Ein eigener unprivilegierter Dienst setzt berechtigte Schritte bei geschlossenem Browser fort. Einen unbestätigten externen Vorgang kennzeichnet der Agent zur Prüfung.
- In der Systemsteuerung legt die Verwaltung je Benutzer eine Obergrenze für jedes Werkzeug fest. Innerhalb dieser Grenze wählt das Konto seine persönlichen Rechte. Lokal angebundene Modelle verarbeiten freigegebene Daten. Für die optionale Cloud-Verbindung wird der eingegebene Text einzeln zur Freigabe vorgelegt.
- T-Mail übergibt die gewählte Unterhaltung und ausdrücklich gewählte PDF-Anhänge. Antworten lassen sich im nativen Editor bearbeiten und anschließend mit Konto, Empfängern und Anhängen prüfen. Die Versandbestätigung unterscheidet SMTP-Annahme, Ablage im Gesendet-Ordner, Ablehnung und einen ungeklärten Ausgang. Kalender, Kontakte und Erinnerungen verwenden die jeweils ausgewählte Ressource.
- In Dateien startet „Mit Agent bearbeiten“ die Arbeit mit der Auswahl. Für T-Word, T-Exel, T-PDF und T-Deck lassen sich Absatz, Zellbereich, PDF-Seiten oder Folien angeben. Der Agent zeigt die Änderung vorab und schreibt eine neue Datei in den freigegebenen Zielordner. Angebote können als bearbeitbare Tabelle mit Verweisen zu den Originalen verglichen werden.
- Eigene Abläufe lassen sich aus Werkzeugen, Quellen, Auslösern und Freigaben zusammenstellen. Die Eingabe per Diktat und der Sprechmodus verwenden lokale Sprachdienste. Gesprochene Fragen und Antworten bleiben im selben Chat.
- Beim Umstieg startet der persönliche Agent mit leerem Datenbestand. Frühere Agent-Einstiege und Hintergrundaufträge werden deaktiviert. Bestehende Archivdaten, normale Konten und Daten der nativen Apps bleiben erhalten. Der zusätzliche Systemdienst erfordert ein Systemupdate mit Neustart.
