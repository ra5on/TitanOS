# TitanOS 0.37.1 — RAM-Kachel mit einem Balken

Ein **App-Update** auf der Systembasis 0.36.1: Es ändert sich nur die
Weboberfläche. Installiert ohne Neustart des NAS, mit automatischem Rückfall.

## Dashboard

In der Darstellung „Balken“ zeigte die RAM-Kachel seit 0.37.0 zwei Balken
untereinander: den bisherigen Balken des verfügbaren RAM und den neuen
geteilten Balken aus Belegt, Schreibcache und Frei. Jetzt gibt es nur noch den
geteilten Balken. Die Prozentzahl (verfügbar) bleibt. Die Darstellungen
„Ring“ und „Verlauf“ sind unverändert.

## Prüfung

Web: `svelte-check`, `npm test` (250), `npm run build`.

## Grenzen und Rückweg

**Nicht geprüft:** die Kachel in einem echten Browser auf echter Hardware.

**Rückweg** auf 0.37.0 oder 0.36.1 über Einstellungen › Updates; es werden
keine Einstellungen geändert.
