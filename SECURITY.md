# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the TitanOS version, what you found and, if possible, steps to reproduce.

You will receive a reply as soon as possible. Once a fix is released, the report will be published with credit to you, unless you prefer to stay anonymous.

## Supported versions

Until version 1.0, only the latest release receives security fixes.

## Update signing

Releases and update manifests are signed. A TitanOS system only installs updates whose signature matches the public key built into the system image. If you ever see an update offered without a valid signature, do not install it and report it as described above.
